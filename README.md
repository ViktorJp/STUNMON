# STUNMON
## Asus-Merlin stunnel Health and Connection Monitor
 v0.2.0 - Last updated: June 14, 2026

<img width="999" height="602" alt="image" src="https://github.com/user-attachments/assets/bd58c62a-6a1f-4db5-b096-9ae3a5d0f02c" />

DESCRIPTION: STUNMON is a standalone stunnel lifecycle manager for Asus Merlin routers running Entware. Manages, monitors, and displays stunnel connections for one or more OpenVPN client slots. stunnel wraps OpenVPN TCP traffic inside a genuine TLS session, making it appear as standard HTTPS to deep packet inspection systems. Designed to operate independently but considered a companion script to VPNMON-R3 (https://github.com/ViktorJp/VPNMON-R3), bringins some integration between the two by sharing a small status file that VPNMON-R3 can optionally read to show [STUN] in its display and skip monitoring any slot that STUNMON owns.
