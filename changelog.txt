v0.2.0      - MINOR: STUNMON is at a stage ready for anyone willing to Beta test it. All remaining necessities have
              been built-in, such as an easy-install wizard to help guide you through the steps to configure a solid
              running stunnel connection, setup menu to configure the script, update menu to check for updates to
              the script, AMTM autoupdate functionality (in preparation), uninstall menu to remove the script and
              all supporting files completely. 

v0.1.0      - Initial release of STUNMON! This script acts as a standalone stunnel lifecycle manager for Asus Merlin 
              routers running Entware. Manages, monitors, and displays stunnel connections for one or more OpenVPN 
              client slots. stunnel wraps OpenVPN TCP traffic inside a genuine TLS session, making it appear as  
              standard HTTPS to deep packet inspection systems. Designed to operate independently of VPNMON-R3 while
              writing a small status file that VPNMON-R3 can optionally read to show [STUN] in its display and skip
              monitoring any slot that STUNMON owns.
